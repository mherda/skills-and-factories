# Wiki

The project's developer knowledge base. Start here, then open only the pages
for the area you're working on. To find them from code paths:
`python3 -I factory/scripts/wiki.py pages-for <path>...`

- New to the codebase: [Architecture overview](architecture/overview.md), then
  [Glossary](glossary.md).
- Decisions (the *rules*) live in `factory/decisions.md`, the plan in
  `factory/roadmap.md`, and open questions and bugs in `factory/issues/`. The
  wiki explains *how things work* and links to decisions by id (D-004).

The page map below is generated by `wiki.py index`. Edit the text above it,
not the map.
